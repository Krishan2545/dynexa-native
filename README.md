# Dynexa Native

Dynexa is an AI-native orchestration infrastructure platform focused on:

- adaptive cognition
- semantic memory
- multi-model routing
- local inference
- cognitive orchestration

---

## Current Stack

- Next.js
- FastAPI
- Ollama
- Phi3
- TinyLlama
- DeepSeek Coder

---

## Features

- semantic memory
- fuzzy retrieval
- memory gating
- adaptive cognition
- multi-model orchestration
- local inference pipeline

---

## Vision

Dynexa aims to evolve into a cognitive infrastructure layer capable of orchestrating adaptive AI systems dynamically across tasks, workflows, and reasoning environments.
